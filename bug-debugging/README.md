# Bug 排查场景策略模板

针对 Bug 排查与调试场景的上下文管理策略集合。

## 模板列表

| 模板 | 策略组合 | 适用场景 | 难度 |
|------|---------|---------|------|
| [手动截断 + 首尾保留](./manual-cut-debugging.md) | manualCut + headTail | 多假设验证、复杂问题排查 | ⭐⭐⭐ 进阶 |
| [滑动窗口 + 日志过滤](./sliding-window-logs.md) | slidingWindow + fieldCut | 日志分析、错误定位 | ⭐⭐ 入门 |

## 场景特点

Bug 排查对话的典型特征：
- 多假设、多方向探索，容易产生无效上下文
- 问题背景信息很重要，不能丢
- 被否定的假设会持续干扰模型
- 排查过程可能持续很长时间，跨天跨周

## 推荐入门路径

1. 先试 **滑动窗口 + 日志过滤** —— 适合日志分析类的简单排查
2. 再学 **手动截断 + 首尾保留** —— 复杂问题排查的核心武器
3. 高阶用 **全量 + 阶段性截断** —— 系统性排查和复盘
