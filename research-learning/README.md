# 学习研究场景策略模板

针对学习、研究、知识沉淀场景的上下文管理策略集合。

## 模板列表

| 模板 | 策略组合 | 适用场景 | 难度 |
|------|---------|---------|------|
| [字段截取 + 滑动窗口](./field-cut-research.md) | fieldCut + slidingWindow | 论文阅读、知识提炼 | ⭐⭐ 入门 |
| [首尾保留 + 主题切换](./head-tail-multi-topic.md) | headTail + slidingWindow | 多主题并行学习 | ⭐⭐⭐ 进阶 |
| [全量 + 阶段性总结](./full-phased-summary.md) | full + manualCut | 深度学习、系统研究 | ⭐⭐⭐⭐ 高阶 |

## 场景特点

学习研究对话的典型特征：
- 探索过程多，"自问自答"式对话产生大量中间内容
- 核心知识点才是需要沉淀的，探索过程不重要
- 可能同时学习多个主题，上下文容易混
- 学习成果需要可回顾、可沉淀

## 推荐入门路径

1. 先试 **字段截取 + 滑动窗口** —— 最直观，立刻感受"干货满满"的上下文
2. 再学 **首尾保留 + 主题切换** —— 多主题并行学习时用
3. 高阶用 **全量 + 阶段性总结** —— 系统学习、深度研究
