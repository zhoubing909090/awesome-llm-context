# 学习研究场景：字段截取 + 滑动窗口策略

## 策略简介

用大模型做学习和研究时，你可能会读论文、查资料、问问题、做总结……但如果把所有探索过程都留在上下文里，到最后想聚焦的时候会发现全是噪音。字段截取策略帮你只保留"干货"（核心结论、关键数据、重要概念），配合滑动窗口让模型聚焦于最近的学习内容。

## 适用场景

✅ **什么时候用这个策略：**

- 读论文、读技术文档、系统性学习新知识
- 自问自答式的探索学习，中间有大量"试错"对话
- 需要提炼核心知识点，过滤掉探索过程
- 多主题并行学习，每个主题独立管理
- 学习内容需要长期沉淀和回顾

❌ **什么时候不建议用：**

- 简单问题、三五轮就能搞懂（没必要用）
- 需要完整追溯思考过程（建议用全量上下文）

## 策略配置

### 主策略：字段截取 (fieldCut)

```json
{
  "strategy": "fieldCut",
  "fieldFilters": {
    "assistant": ["conclusion", "key_concept", "data", "example"],
    "user": ["question", "summary"]
  },
  "keepLatestFull": 1,
  "preserveKeywords": ["核心结论", "关键数据", "重要概念", "定义"]
}
```

**参数说明：**
- `fieldFilters` — 只保留结论、关键概念、数据、示例等关键字段
- `keepLatestFull: 1` — 最近 1 条消息保留完整内容（正在讨论的问题不能裁）
- `preserveKeywords` — 包含这些关键词的段落即使在中间也保留

### 辅助策略：滑动窗口

```json
{
  "strategy": "slidingWindow",
  "windowSize": 12,
  "includeSystemPrompt": true
}
```

当你切换到新的学习主题时，用滑动窗口让旧主题自然"滑出"上下文。

## 使用技巧

### 1. 什么是"字段截取"？

举个例子，模型的回答通常长这样：

```
好的，我来解释一下这个概念。

首先，我们需要了解背景……（一大段铺垫）

核心概念是：XXXXXX  ← 这个要保留

具体来说，有几个要点：
1. XXX
2. XXX
3. XXX

举个例子：……（举例说明） ← 这个可能要保留

总结一下，……（重复前面的话）← 这个可以裁掉
```

字段截取就是把模型回答中**不是核心信息的部分**裁掉，只留下干货。探索过程中的那些"我想想""可能是这样""不对应该是那样"全部过滤掉。

### 2. 不同学习内容的参数调整

| 学习类型 | 保留字段 | 窗口大小 | 裁剪强度 |
|---------|---------|---------|---------|
| 论文阅读 | 结论、数据、方法 | 8-10 轮 | 强 |
| 概念学习 | 定义、例子、对比 | 10-12 轮 | 中 |
| 编程学习 | 代码、原理、注意事项 | 10-15 轮 | 中 |
| 语言学习 | 例句、语法点、对比 | 12-15 轮 | 弱 |
| 研究探索 | 假设、证据、结论 | 6-8 轮 | 强 |

### 3. 学习路径推荐

```
第1阶段：全量上下文 → 广泛探索，发散思维
     ↓ 有了初步理解之后
第2阶段：字段截取 → 提炼核心，过滤噪音
     ↓ 进入深度学习阶段
第3阶段：首尾保留 → 头部保留核心概念，尾部深入讨论
     ↓ 学完一个主题
第4阶段：滑动窗口 → 旧主题滑出，开始新主题
```

### 4. 配合"主动总结"效果翻倍

每学完一个小模块，主动让模型做一个 3-5 句话的总结，然后把这条总结作为"锚点"保留在上下文中。字段截取策略会自动保留这种总结性质的内容。

## 效果案例

### 用户案例：RAG 技术系统性学习

**背景：** 从零开始系统学习 RAG（检索增强生成）技术，涉及向量数据库、Embedding、检索策略、评估方法等多个子主题，学习周期两周。

**使用前：**
- 两周对话 80+ 轮
- 学到后面，前面的概念开始混淆
- Token 消耗：约 42,000
- 经常需要"重新讲一遍"某个概念
- 学习效率：平均每天掌握 1.5 个知识点
- 学完之后回顾困难，知识散落在各轮对话里

**使用字段截取+滑动窗口后：**
- 两周对话 65 轮
- 上下文中都是精炼过的核心知识点，没有冗余
- Token 消耗：约 21,000（节省 50%）
- 模型回答质量明显更高——因为上下文都是干货
- 学习效率：平均每天掌握 2.5 个知识点（提升 67%）
- 可以导出完整的学习笔记（字段截取后的内容就是现成笔记）

**关键设置：**
- 字段截取：保留结论、关键概念、数据、示例
- 滑动窗口：10 轮，聚焦最近的学习内容
- 每个子主题学完后主动生成一份"迷你总结"

**用户评价：**
> "以前用 AI 学习，聊到后面上下文里全是我东问西问的碎片，真正重要的东西反而被淹没了。用了字段截取之后，上下文里全是干货，就像有个学习助理在帮我整理笔记一样。"
