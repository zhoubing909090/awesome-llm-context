# 学习研究：首尾保留 + 主题切换策略

## 策略简介

同时学好几个主题的时候，最怕的就是"串台"——A主题的知识混到B主题的讨论里。首尾保留策略让每个主题的核心概念始终在位，配合手动截断在主题之间切换，确保每个主题的上下文纯净独立。

## 适用场景

✅ **什么时候用这个策略：**

- 同时学习多个主题或技术方向
- 学习中需要在不同主题之间来回切换
- 每个主题有独立的知识体系和术语
- 需要保持每个主题的学习进度和脉络
- 复习阶段快速切换不同主题

❌ **什么时候不建议用：**

- 只学一个主题（没必要用）
- 主题之间高度关联、需要交叉参考（建议用全量+标签管理）

## 策略配置

### 主题内学习：首尾保留 (headTail)

```json
{
  "strategy": "headTail",
  "headReserve": 4,
  "tailReserve": 6,
  "middleStrategy": "key_points"
}
```

**参数说明：**
- `headReserve: 4` — 保留头部 4 条（主题介绍 + 核心概念 + 学习目标 + 前置知识）
- `tailReserve: 6` — 保留尾部 6 条（当前学习内容的最新讨论）
- `middleStrategy: "key_points"` — 中间内容只保留关键知识点摘要

### 主题切换：手动截断标记

```json
{
  "strategy": "manualCut",
  "cutPoint": "topic_boundary",
  "mode": "archived",
  "includeHead": 1,
  "archiveTag": "主题A"
}
```

切换主题时，在当前主题的最后一条消息设置截断点，并打上"主题标签"。以后切回来的时候，可以快速恢复这个主题的上下文。

## 使用技巧

### 1. 多主题学习的"分层管理法"

```
第1层：学习总目标（永久保留，最头部）
       例："我正在系统学习AI工程化，包括RAG、Agent、Fine-tuning三个方向"

第2层：当前主题核心概念（头部保留区）
       例：当前学RAG，保留RAG的定义、核心组件、关键指标

第3层：当前学习内容（尾部活跃区）
       例：正在讨论向量数据库的选型对比

第4层：已归档主题（截断归档区）
       例：Agent和Fine-tuning的内容暂时归档，不参与当前计算
```

### 2. 主题切换的标准动作

从主题 A 切换到主题 B 时，按这个流程来：

1. 让模型用 3 句话总结主题 A 当前的学习进度
2. 设一个截断点，打上"主题A"标签（可恢复模式）
3. 在对话开头加入主题 B 的核心概念（如果之前学过，从归档中恢复）
4. 开始主题 B 的学习

> 💡 这样做的好处是：每个主题的学习进度都被"打包封存"了，不会互相干扰。下次切回来的时候，解包就能继续。

### 3. 不同学习阶段的头部内容

| 学习阶段 | 头部保留内容 | 条数 |
|---------|------------|------|
| 入门期 | 主题简介 + 核心概念 + 学习目标 | 3 条 |
| 进阶期 | 核心概念 + 知识框架 + 已掌握要点 + 当前问题 | 4 条 |
| 深入期 | 知识框架 + 待解决问题 + 研究方向 + 参考资料 | 4-5 条 |
| 复习期 | 知识框架 + 重点总结 + 薄弱点 | 3-4 条 |

### 4. 主题之间有交叉怎么办？

如果学习过程中发现两个主题有交叉（比如 RAG 和 Embedding 紧密相关）：

- **浅度交叉** → 在当前主题里简单提一下，标注"详见XX主题"
- **深度交叉** → 开一个新的"交叉主题"任务专门讨论，两个主主题保持纯净
- **强关联** → 合并为一个大主题，用子标签管理不同模块

## 效果案例

### 用户案例：AI 工程师系统学习计划

**背景：** 一位后端工程师转型 AI 工程，同时学习 RAG、Agent、Fine-tuning 三个方向，计划用 2 个月系统掌握。

**使用前：**
- 三个方向混在一个对话里，经常串台
- 学到 Agent 的时候，模型用 RAG 的概念来解释，越学越乱
- Token 消耗：约 52,000
- 学习效率：平均每天掌握 1 个知识点
- 经常需要"重新讲一遍基础"
- 两个月下来，感觉学了不少但知识体系不清晰

**使用首尾保留+主题切换后：**
- 每个方向独立管理，上下文纯净
- 切换方向时，模型快速进入对应主题的状态
- Token 消耗：约 28,600（节省 45%）
- 学习效率：平均每天掌握 2 个知识点（提升 100%）
- 每个方向有清晰的知识框架和学习进度
- 两个月下来，形成了完整的知识体系

**关键设置：**
- 每个主题独立对话任务，用首尾保留策略
- 头部保留：主题核心概念 + 知识框架 + 学习目标
- 主题之间切换时，归档当前主题，加载新主题
- 每周用一次全量上下文，做跨主题的串联和复盘

**用户评价：**
> "同时学好几个东西最怕的就是混淆。用了主题切换之后，每个方向的知识都整整齐齐的，学起来不串台，效率翻了一倍。"
