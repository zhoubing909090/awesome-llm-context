# 代码审查场景策略模板

针对代码审查（Code Review）场景的上下文管理策略集合。

## 模板列表

| 模板 | 策略组合 | 适用场景 | 难度 |
|------|---------|---------|------|
| [滑动窗口 + 字段截取](./sliding-window-code-review.md) | slidingWindow + fieldCut | 逐段代码审查、单模块深度Review | ⭐⭐ 入门 |
| [首尾保留 + 全量切换](./head-tail-review.md) | headTail + full | 跨文件审查、架构级Review | ⭐⭐⭐ 进阶 |
| [手动截断 + 多轮对比](./manual-cut-compare.md) | manualCut | 多种方案对比审查 | ⭐⭐⭐ 进阶 |

## 场景特点

代码审查对话的典型特征：
- 代码输出占比高，Token 消耗大
- 每轮讨论相对独立，对历史依赖适中
- 需要保持审查标准一致（系统提示重要）
- 中间有大量试探性讨论，容易产生冗余

## 推荐入门路径

1. 先试 **滑动窗口 + 字段截取** —— 最容易上手，效果立竿见影
2. 熟悉后尝试 **首尾保留** —— 适合更复杂的审查场景
3. 高阶玩家用 **手动截断** —— 精准控制上下文边界
