# 产品设计场景策略模板

| 模板 | 策略组合 | 适用场景 | 难度 |
|------|---------|---------|------|
| [过期时间 + 首尾保留](./expire-time-design.md) | expireTime + headTail | 快速迭代、方案多变 | ⭐⭐ 入门 |
| [滑动窗口 + 灵感收集](./sliding-window-brainstorm.md) | slidingWindow | 头脑风暴、创意发散 | ⭐⭐ 入门 |

## 场景特点

产品设计对话的典型特征：
- 迭代快，方案说变就变，旧方案容易干扰
- 需要保持产品定位/目标用户等核心锚点不变
- 头脑风暴阶段有大量发散内容，大部分不会落地
- 多方案对比时，信息量大且容易混淆

## 推荐入门路径

1. 先试 **过期时间 + 首尾保留** —— 最通用，自动清理过时讨论
2. 再学 **滑动窗口 + 灵感收集** —— 头脑风暴阶段的利器
3. 进阶用 **手动截断 + 方案对比** —— 多方案决策时精准控制
