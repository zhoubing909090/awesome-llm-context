# 数据分析场景策略模板

针对数据分析、报表生成、异常排查场景的上下文管理策略集合。

## 模板列表

| 模板 | 策略组合 | 适用场景 | 难度 |
|------|---------|---------|------|
| [滑动窗口 + 过期时间](./sliding-window-analysis.md) | slidingWindow + expireTime | 实时监控、探索式分析 | ⭐⭐ 入门 |
| [首尾保留 + 字段截取](./head-tail-reporting.md) | headTail + fieldCut | 报表生成、结论输出 | ⭐⭐⭐ 进阶 |

## 场景特点

数据分析对话的典型特征：
- 数据量大，原始数据占用大量 Token
- 时效性强，旧数据很快失去价值
- 探索过程多，大量假设被排除
- 口径一致性很重要，口径错了全白搭

## 推荐入门路径

1. 先试 **滑动窗口 + 过期时间** —— 最常用，日常分析都能用
2. 再学 **首尾保留 + 字段截取** —— 生成分析报告、提炼结论时用
