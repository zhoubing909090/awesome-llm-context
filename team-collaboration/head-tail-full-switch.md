# 团队协作：首尾保留 + 全量切换策略

## 策略简介

团队日常讨论用首尾保留保持聚焦，需要全面回顾时一键切换全量上下文。兼顾"平时高效"和"关键时候信息完整"。

## 适用场景

✅ **什么时候用这个策略：**

- 团队日常用 AI 辅助讨论和决策
- 大部分时间需要聚焦当前话题，但偶尔需要回顾历史
- 团队成员轮流跟进同一个 AI 对话
- 需要平衡"上下文精简"和"决策可追溯"
- 项目周期长，阶段多

❌ **什么时候不建议用：**

- 全程都需要完整上下文（直接用全量）
- 讨论内容非常简单，没什么历史包袱（直接滑动窗口就行）

## 策略配置

### 日常模式：首尾保留

```json
{
  "strategy": "headTail",
  "headReserve": 4,
  "tailReserve": 8,
  "middleStrategy": "summary"
}
```

**参数说明：**
- `headReserve: 4` — 保留头部 4 条（项目目标 + 核心约束 + 关键决策 + 成员分工）
- `tailReserve: 8` — 保留尾部 8 条（当前讨论的最新进展）
- `middleStrategy: "summary"` — 中间内容摘要化

### 回顾模式：全量上下文

```json
{
  "strategy": "full",
  "note": "方案评审/项目复盘/新人接手时临时切换"
}
```

需要完整信息时一键切换，用完再切回首尾保留。

## 使用技巧

### 1. 头部"四条金刚"

团队协作场景下，建议头部固定保留这四条信息：

| 序号 | 内容 | 为什么重要 |
|------|------|-----------|
| 第1条 | **项目目标** | 所有人对齐"我们在做什么" |
| 第2条 | **核心约束** | 技术限制、时间限制、资源限制 |
| 第3条 | **关键决策记录** | 已经定了的事，别反复讨论 |
| 第4条 | **成员分工** | 谁负责什么，各司其职 |

这四条是团队的"共同记忆锚点"，有了它们，不管谁来跟 AI 对话，起点都是一致的。

### 2. 切换全量的 5 个关键时刻

| 场景 | 为什么切全量 | 切多久 |
|------|------------|--------|
| 方案评审 | 需要看到完整的决策过程和取舍理由 | 评审期间 |
| 新人接手 | 让新人快速了解全部前因后果 | 1-2 天，熟悉后切回首尾保留 |
| 项目复盘 | 回顾整个过程，总结经验教训 | 复盘当天 |
| 出现争议 | "当时为什么这么定的？"——查记录 | 争议解决后切回 |
| 重大决策前 | 确保决策基于完整信息，不是片面的 | 决策当天 |

### 3. 团队使用约定

为了让多人共用一个对话任务不混乱，建议团队约定以下规则：

1. **发言署名**：每条人类消息开头加个名字，如 `[张三]` 或 `[李四]`
2. **决策标记**：重要决定用 `【决策】` 开头，方便日后检索
3. **阶段归档**：每个里程碑设一个截断点，打上阶段标签
4. **每日同步**：每天早上花 5 分钟，看一眼头部的关键决策 + 尾部最新进展

### 4. 成员轮流跟进的最佳实践

```
周一：张三跟进，讨论方案A
      ↓ 下班前：让模型生成今日进展摘要，更新到头部
周二：李四接手
      打开对话 → 看头部的目标+决策+昨日进展 → 看尾部的最新讨论 → 5分钟进入状态
      ↓ 继续推进
周三：王五跟进
      同样的流程，无缝衔接
...
周五：切换全量上下文，做周复盘
```

## 效果案例

### 用户案例：创业团队 AI 辅助产品开发

**背景：** 一个 4 人创业团队用 AI 辅助产品开发，涵盖需求、设计、开发、测试全流程。团队成员轮流跟 AI 对话推进不同模块。

**使用前：**
- 每人各开各的对话，信息孤岛
- 每天站会要花 15 分钟同步"你跟 AI 聊了啥"
- 决策散落在不同对话里，经常"当时谁说的来着？"
- Token 总消耗高（重复讨论多）
- 新人加入要花一周才能跟上进度

**使用首尾保留+全量切换后：**
- 共用一个对话任务，信息集中
- 头部四条金刚 + 尾部最新讨论，任何人5分钟进入状态
- 决策有标记，可追溯，不扯皮
- Token 总消耗下降约 35%（重复讨论减少）
- 新人加入 1 天就能上手
- 站会同步时间从 15 分钟降到 5 分钟

**关键设置：**
- 日常：首尾保留，聚焦当前推进
- 评审/复盘：切换全量，全面回顾
- 头部固定：项目目标 + 技术约束 + 关键决策 + 分工
- 每周五下午：全量上下文做周复盘，更新下周计划

**用户评价：**
> "团队共用一个 AI 对话任务，刚开始担心会乱。用了首尾保留之后，平时精简高效，需要的时候切全量看完整记录，完美平衡了效率和完整性。"
