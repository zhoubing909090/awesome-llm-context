# Awesome LLM Context Strategies

> 大模型对话上下文管理最佳实践与策略模板集合。让每一次 AI 对话都精准、高效、不跑偏。

## 📌 什么是上下文管理？

跟大模型对话聊久了，你有没有遇到过这些问题：

- 😵 模型逐渐"忘记"最初的设定，回答越来越跑题
- 🤯 之前讨论过的错误方案，模型隔几轮又拿出来说
- 💰 对话越长，Token 消耗越高，但大部分都是冗余内容
- 🔒 不小心把敏感信息混进了上下文，有泄露风险

这些问题统称为**上下文漂移（Context Drift）和上下文污染（Context Pollution）**。学术研究已经证实，当对话超过一定轮次后，模型回答质量会下降 30% 以上。

上下文管理，就是通过策略化的方式，控制每次发送给模型的内容范围，让模型始终在干净、聚焦的上下文中工作。

## 🧠 六大核心策略

| 策略 | 原理 | 最佳场景 |
|------|------|---------|
| **首尾保留 (headTail)** | 保留头部系统设定 + 尾部最新对话，中间裁剪 | 长任务、需保持初始设定 |
| **滑动窗口 (slidingWindow)** | 仅保留最近 N 条消息 | 时效性强的连续对话 |
| **手动截断 (manualCut)** | 在某处设截断点，之前的不再发给模型 | 方向转变、排除错误假设 |
| **过期时间 (expireTime)** | 超过有效期的对话自动失效 | 多任务切换、临时讨论 |
| **字段截取 (fieldCut)** | 按字段剔除敏感或无关内容 | 数据安全、精简输出 |
| **全量上下文 (full)** | 发送全部历史 | 需要完整记忆的场景 |

## 🚀 如何使用这些模板

### 方式一：手动配置
1. 浏览上面的速查表，找到你需要的场景
2. 点击对应模板，查看详细说明和参数
3. 在你的 AI 对话工具中手动应用策略

### 方式二：TCK 一键导入（推荐）
所有模板均兼容 [TaskContext-Kit (TCK)](#) 工作台，复制模板中的 JSON 配置，在 TCK 中粘贴即可一键导入。

> 💡 **TCK 是什么？** 一款专业的大模型上下文管理工作台，支持六大策略可视化配置、永久对话存储、多模型切换等功能。无门槛使用，无需会员，打开浏览器就能用。

- 策略配置（JSON 格式）
- 使用技巧
- 效果案例（可选但推荐）
- 相关模板推荐
