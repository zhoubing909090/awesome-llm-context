# 内容创作场景策略模板

针对文章写作、文案创作、内容策划场景的上下文管理策略集合。

## 模板列表

| 模板 | 策略组合 | 适用场景 | 难度 |
|------|---------|---------|------|
| [首尾保留 + 滑动窗口](./head-tail-writing.md) | headTail + slidingWindow | 长文写作、风格一致性要求高 | ⭐⭐ 入门 |
| [字段截取 + 风格保持](./field-cut-style.md) | fieldCut + headTail | 多版本对比、风格快速切换 | ⭐⭐⭐ 进阶 |
| [过期时间 + 选题策划](./expire-time-topic.md) | expireTime + slidingWindow | 多选题并行、灵感收集 | ⭐⭐ 入门 |

## 场景特点

内容创作对话的典型特征：
- 风格一致性要求高，跑偏了读者一眼就能看出来
- 创作过程有阶段性，不同阶段策略不同
- 中间有很多"好的""改一下""再试试"之类的无效对话
- 写作目标和读者画像需要始终明确

## 推荐入门路径

1. 先试 **首尾保留 + 滑动窗口** —— 写长文必备，防止风格跑偏
2. 再学 **过期时间 + 选题策划** —— 适合同时推进多个选题
3. 进阶用 **字段截取** —— 多版本对比时只保留关键内容
